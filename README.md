## 搬瓦工支持哪些信用卡

搬瓦工的信用卡通道接入的是 Stripe，支持 **Visa、Mastercard、American Express** 三种主流国际卡。

国内用户常见的几种情况：

1. **双币信用卡（Visa/MC 标志）**：一般都能用，结算以美元计价，银行按实时汇率换算成人民币扣款，会有一笔货币转换手续费（各银行不同，通常 1.5%–2%）。
2. **全币种信用卡**：最顺滑，无外汇手续费，直接走美元通道，推荐。
3. **银联单标卡**：不行，Credit Card 通道识别不了，只能走 Unionpay 那个独立入口。
4. **虚拟信用卡（如 Depay 等）**：部分能用，但搬瓦工对某些高风险 BIN 段会触发反欺诈，遇到被拒需要换其他卡或换支付方式。

一个容易忽视的地方：账户**充值余额（Add Funds）** 这个功能，只接受 PayPal 和信用卡，支付宝、银联在这里都不行。所以如果你想提前往账户里存钱、让 VPS 到期自动扣款续费，信用卡是最顺手的工具。

## 下单时怎么用信用卡付款

流程整体不复杂，选好套餐加入购物车之后，结账页面（Checkout）会列出四个付款方式：PayPal、Credit Card、Unionpay、Alipay。选 Credit Card，然后填写以下信息：

- 持卡人姓名（拼音，与卡面一致）
- 卡号（16 位）
- 有效期（MM/YY）
- CVV 安全码（卡背面三位）
- 账单地址（Billing Address）

账单地址这一项让不少人卡住。填国内地址完全没问题——直接填真实居住地址的拼音，省/市/区/街道对应填 State/City/Address 各字段，邮政编码填正确。不需要填美国地址，Stripe 不强制要求地址与发卡行匹配。

填好点 Complete Order，然后 Pay now，Stripe 处理通常几秒内完成，成功后邮件通知到账，后台 3–5 分钟激活 VPS。

## 续费和充值余额：两个场景分开说

**场景一：账单到期直接付款**

VPS 到期前搬瓦工会发邮件，账单页面里点 Make Payment，再选 Credit Card 走一遍正常付款流程。如果上次购买时绑定了卡，这次可以直接确认，不用重填。

**场景二：提前往账户余额（Add Funds）充值**

这里要注意：最低充值额度是 $50，且支付宝、银联都不可用，只能 PayPal 或信用卡。充值后余额到账是实时的，VPS 到期时会自动从余额扣款。这个方式对经常忘记续费的人来说其实挺实用——充一次，后续自动处理。

回过头来说，充值功能的实际使用场景并不多。只有在你想一次性预付、避免多次小额操作时才有意义。平时到期了直接去账单页付款就行，没必要特意充余额。

## 信用卡被拒怎么办

遇到付款失败，大概率是以下几个原因：

**1. 银行风控拦截**
国内银行对境外小额外汇交易偶尔会误判拦截。解决办法：先发短信或打电话给发卡行说明是正常消费，再试一次。

**2. 卡的国际交易功能未开通**
部分双币卡出厂默认关闭境外消费功能，需要去银行 APP 或柜台开通。

**3. 触发反欺诈**
搬瓦工后台对来自"高风险国家/地区"的 IP 购买有额外审查，付款时建议**不要挂代理**，用干净的国内网络环境直接操作。这一点很多人踩过坑，代理环境下 Stripe 更容易触发人工审核甚至直接拒单。

**4. 卡的余额/额度不足**
这个不用多说，但值得一提的是：由于汇率浮动，美元价格换算成人民币可能比你预估的多几块，确保卡内有足够余额。

换个角度——实在搞不定信用卡，直接用支付宝或银联也完全没问题，操作更简单，退款原路返回也方便。
